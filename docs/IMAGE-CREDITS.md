## جایگزینی تصویر

هر عکس را کارفرما می‌تواند از پنل «کاتالوگ ماساژها» ← ویرایش هر مورد ←
«تصویر اصلی» عوض کند (JPG/PNG/WebP تا ۴ مگابایت). فایل جدید در
`public/uploads/site/` ذخیره می‌شود و تصویر پیش‌فرض دست‌نخورده می‌ماند.
تصویرسازی‌های SVG (`public/assets/img/massage/*.svg`) فقط وقتی استفاده می‌شوند
که برای آن مورد تصویری انتخاب نشده باشد.
